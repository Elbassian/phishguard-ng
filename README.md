# PhishGuard NG

AI-enabled cybersecurity awareness MVP for the 3MTT × MIT Open Learning Universal AI Programme Innovation Challenge.

## MVP features
- Suspicious-message risk analysis prototype
- Explainable warning indicators
- Cybersecurity awareness learning cards
- Interactive OTP/social-engineering quiz
- Responsible AI and privacy guidance

## Important
This MVP is an awareness/decision-support prototype. Its message checker uses an explainable indicator-based risk engine; it is **not** a guaranteed malware/phishing detector. Do not enter passwords, OTPs, PINs, banking credentials, or other sensitive personal information.

## Deployment
This is a static web app and can be deployed on GitHub Pages, Netlify, Vercel, or another static hosting service.
